# Roadmap

## 0.1 — Public beta

- Publish the sanitized repository.
- Verify clean-profile installation of only `skill/betteredit`.
- Verify all 240 browser previews from a clean clone.
- Recruit 5–10 external testers from different video workflows.
- Convert installation friction into documented issues.

## 0.2 — Integration layer

- Add a stable adapter interface for agent and renderer integrations.
- Resolve friction reported by at least three independent one-skill installations.
- Publish a cleared 30-second installation-to-render walkthrough.
- Add example bindings for horizontal, vertical, and square deliverables.
- Add template-diff and migration tooling.
- Publish a small, reproducible end-to-end example using cleared media.

## 0.3 — Community library

- Accept externally authored families and previews.
- Add contribution scoring for visual differentiation and accessibility.
- Add multilingual designed-text and subtitle examples.
- Publish monthly adoption and maintenance notes.

## 1.0 — Stable contracts

- Freeze schema compatibility guarantees.
- Document deprecation and migration policy.
- Maintain multiple renderer adapters.
- Demonstrate real use by independent creators or projects.
