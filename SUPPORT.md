# Support

Use GitHub Discussions for usage questions after Discussions is enabled. Use issues for reproducible defects and scoped feature requests. Use private vulnerability reporting for security concerns.

Before asking for help, run:

```bash
node --version
npm run validate:library
npm run audit:public
```

Include the command, sanitized output, operating system, Node.js version, and affected template IDs. Never upload private media or credentials to a support thread.
