# Code of conduct

BetterEdit contributors must communicate respectfully, critique work rather than people, respect privacy and licensing boundaries, and avoid harassment, discrimination, threats, doxxing, or deliberate disruption.

Report conduct concerns privately to the primary maintainer through the contact method on their public GitHub profile. The maintainer may edit or remove content, close discussions, restrict participation, or ban accounts when needed to protect the community.

The primary maintainer must disclose conflicts of interest and should ask a neutral core maintainer to handle any report in which the primary maintainer is involved.
