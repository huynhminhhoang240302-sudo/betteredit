## Qualitative evidence

For each external use, record:

- who used it, with permission to name them;
- the public project or output link;
- which BetterEdit capability was used;
- the measurable or observable benefit;
- whether the user returned, contributed, or opened an issue.
- whether the user installed only `skill/betteredit`, and any extra setup they unexpectedly needed.

Private analytics such as clone counts may be useful for internal planning, but prioritize evidence an application reviewer can verify publicly.
