# Release checklist

1. Update `CHANGELOG.md` and version metadata.
2. Run `npm run validate` from a clean checkout.
3. Run the full preview validator for releases that change videos or manifests.
4. Confirm public audit and GitHub security checks pass.
5. Review dependency and license changes.
6. Verify the offline browser on desktop and mobile.
7. Create a signed or verified tag where practical.
8. Publish release notes with compatibility and migration information.
9. Record release metrics in the maintenance evidence log after the reporting period.
