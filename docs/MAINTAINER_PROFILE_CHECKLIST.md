# Maintainer profile checklist

- Public GitHub profile and avatar.
- Bio that accurately describes the maintainer's role.
- Public contact route that does not expose a private inbox unnecessarily.
- BetterEdit pinned on the profile.
- Contributions, releases, issue triage, and PR reviews visible under the same account.
- ChatGPT-account email confirmed separately for the OpenAI application.
- OpenAI Organization ID recorded privately, never committed.
- No claim of OpenAI employment, partnership, endorsement, or acceptance unless formally true.
