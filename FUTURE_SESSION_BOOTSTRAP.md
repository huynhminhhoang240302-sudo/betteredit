# Future GPT-5.6-sol bootstrap and user-material workflow

Use this document to start a new video session, audition and select short-edit templates, and bind the user's chosen media without rebuilding the editing grammar. The package contains **240 curated choreography templates in 32 families**, plus one real, playable, low-resolution procedural MP4 demonstration with synthetic guide audio for every template ID. A template defines the narrative job, slot topology, timing, focal path, transition logic, motion, audio events, and continuity states. The generic preview, the user's **style pack**, and the user's **content binding** remain separate and replaceable.

The 240 v2 preview MP4s demonstrate choreography; they are not final user-bound edits. Play them through `template-browser.html` or directly under `previews/videos/<group>/`, then replace their generic shapes, labels, textures, and guide audio with user-approved assets through the declared slots. Spatial composition is a first-class property: 204 previews are non-frontal, distributed across yawed planes, tilt planes, depth stacks, corridors, oblique splits, and orbital stages.

## Layer contract

Keep these four things independent:

1. **Family:** stable narrative grammar, such as human-to-world, whole-part-whole, evidence escalation, causal chain, or reassembly. A portrait portal is a presentation form selected only when justified by the material or user direction.
2. **Template variant:** curated choreography with bounded duration, slot topology, reveal order, focal path, motion sequence, audio map, and entry/exit continuity.
3. **Generic rendered preview:** the supplied low-resolution procedural MP4 and poster that demonstrate the variant's choreography and guide-audio relationships; never treat these stand-ins as final content.
4. **Style pack:** user-approved serif fonts, palette, surfaces, lighting, grain, geometry, easing, and sound palette. Quick Mix-derived surface treatment is never automatic; use it only when the user explicitly selects that direction.
5. **Content binding:** the user's exact media, source ranges, crop anchors, text, data, licences, and optional masks/depth assets.

Palette, mirroring, aspect ratio, font choice, easing, grain, and simple speed changes do **not** create new template IDs.

## Template-selection query examples

These examples are tool-agnostic filters. Return 3–5 ranked candidates, never the entire registry. Rank by narrative fit, asset availability, continuity, production cost, then style compatibility.

After filtering, open `template-browser.html`, use the **Spatial composition** filter to compare stage geometry, play each candidate, and unmute the local player when evaluating guide-audio timing. The files live at `previews/videos/<group>/<template-id>.mp4`; poster and media metadata—including spatial and settle modes—live in `previews/preview-manifest.json`. Validate the supplied preview set with `node tools\validate-previews.mjs` before relying on it after any package modification.

The canonical spatial distribution must remain exact: `frontal` 36, `yaw_left` 23, `yaw_right` 22, `tilt_plane` 26, `depth_stack` 37, `corridor` 40, `oblique_split` 37, and `orbital` 19. This is 204/240 non-frontal templates. Do not convert the spatial axis into a style-pack choice or flatten all selected templates to frontal staging.

## User decision workflow

The session should do the analysis and narrow the choices. The user should only be asked to make decisions that affect the creative result.

1. **User supplies the brief:** script/topic, target platform and duration, any locked visual references, and available media.
2. **Session creates the beat map:** one narrative job per beat, plus duration and required slots.
3. **Session proposes and demonstrates candidates:** 3–5 template IDs for each important beat, with one-sentence reasons, effort level, missing materials, continuity implications, and links to their playable generic MP4s.
4. **User auditions and chooses template direction:** play the demonstrations in `template-browser.html`, then select IDs or approve the session's recommended sequence.
5. **Session proposes a style pack:** serif font specimen, palette, surface, light, motion, and sound. Translate any banned reference motif into an allowed substitute.
6. **User approves or edits the style pack.** This approval does not yet approve fabricated media.
7. **Session builds the content-binding manifest:** map every exact file to a slot; flag crop anchors, source text, licences, and every `WAITING_FOR_USER_MATERIAL` field.
8. **User supplies missing required media or explicitly authorizes a fallback.** Optional empty slots may be omitted only when the template declares that fallback.
9. **Session renders the approval packet:** one typography-heavy still, one media-heavy still, one data/mechanism still, and one transition-extrema frame.
10. **User approves the visual family.** Only then may it propagate across many templates.
11. **Session renders a low-resolution user-bound sequence preview:** after replacing the procedural stand-ins, verify the real style, media, pacing, eye trace, voice timing, semantic audio, and continuity before expensive final work.
12. **User gives sequence notes; session revises and renders final.** The session runs the delivery gate and reports the exact output facts.

When a user-selected reference itself contains a banned motif, preserve only its useful intent—such as pacing, depth, contrast, format change, or reveal timing—and replace the motif with an allowed construction.

## Definition of done

A template-bound edit is complete only when all conditions below pass in the **rendered output**:

- [ ] Every beat has one named narrative job, focal point, and primary attention cue.
- [ ] Selected template IDs and their canonical timing/choreography are recorded; any adaptation is documented.
- [ ] Every required slot is bound to a user-approved asset or an explicitly authorized fallback; no silent stock or AI substitution exists.
- [ ] Assets meet resolution, duration, handle, crop, focal-anchor, source-text, and licence requirements.
- [ ] The approved style pack is recorded and each real serif font role loads in a captured font specimen and in the first rendered frame where that role appears.
- [ ] Every designed title, caption, label, numeral, unit, chart, credit, and placeholder resolves to a true serif face.
- [ ] No decorative top/bottom notes, split edge metadata, note rail, repeated diagonal hatch/crossing field, pseudo-wayfinding counter, or accent kicker with detached short rule appears at any sampled time or transition extreme.
- [ ] The selected template's spatial mode is preserved at a representative hold. A bounded oblique content plane is not misclassified as a decorative diagonal field, and no decorative hatch/crosshatch/stripe field is introduced inside it.
- [ ] Designed text is screen-facing or its diegetic projection remains within 18° yaw, 10° pitch, 5° roll, 80% apparent dimensions, safe areas, and phone-size readability.
- [ ] One primary attention cue dominates; camera and object motion have semantic verbs; unmotivated drift is absent.
- [ ] Entry and exit continuity states are declared and the sequence preserves eye trace, orientation, motion vector, object identity, or a justified reset.
- [ ] Text limits, safe areas, phone-size readability, captions, contrast, flicker, and accessibility pass.
- [ ] Audio events have visible/narrative causes; dialogue is intelligible; the final narrated web encode targets approximately −14 to −16 LUFS-I and no higher than −1.0 dBTP unless delivery specifications require otherwise.
- [ ] Full playback, transition-extrema inspection, encoded-file verification, and output metadata checks pass.
- [ ] Delivery report lists templates, style pack, inserted files, serif fonts, adaptations, QA result, duration, canvas, frame rate, codecs, and absolute output paths.

Only after all checks pass may the report state:

> Permanent style lock passed: all designed text resolves to serif; no top/bottom decorative notes or metadata rails; no diagonal hatch/crossing fields; no pseudo-wayfinding slash counters; and no small accent kicker with detached underline. Representative frames and transition extrema were checked in the final render.
